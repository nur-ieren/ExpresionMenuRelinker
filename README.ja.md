# ExpressionMenu Relinker

[English](README.md)

コピー先フォルダ内のVRChat用ExpressionMenuが参照しているSubMenuを、コピー元のものからコピー先のものへ、フォルダ指定だけで一瞬で付け替えるUnityエディタ拡張です。

作りがほとんど同じExpressionMenuをフォルダごとに分けて管理し、新しいアバター用にフォルダをコピーすると、コピー先のMenuは**コピー元のSubMenu**を参照したままになります。これを1つずつ手作業で直すのは手間がかかるため、まとめて処理します。

## 動作環境

- Unity 2022.3.22f1(開発に使用しているバージョン)
- VRChat SDK3 Avatars(`VRCExpressionsMenu`)

VRC SDKの型を直接参照していないので、SDKのバージョン差異の影響を受けません。

## 導入

次の場所にスクリプトを配置してください。

```
Assets/nur_ieren/ExpressionMenuRelinker/ExpressionMenuRelinker.cs
```

`Editor` フォルダやasmdefは不要です。ファイル全体を `#if UNITY_EDITOR` で囲んであります。

## 使い方

1. 上部メニューの **nur_ieren → ExpressionMenu 参照付け替え** を開きます。
2. **コピー先フォルダ**を指定します。
3. **コピー元フォルダ**も指定します(任意)。
4. 「スキャン」を押すと、付け替え対象が一覧に表示されます。
5. 内容を確認して(個別にチェックを外すこともできます)、「付け替え実行」を押します。

実行後は自動で再スキャンされます。対象が0件になれば完了です。

## 付け替えの仕組み

コピー先フォルダ内のすべてのExpressionMenuについて、各SubMenu参照を調べます。すでにコピー先フォルダ内を参照しているものは変更しません。

| コピー元フォルダ | 対象 | 対応付け |
| --- | --- | --- |
| 指定あり | コピー元フォルダ内を参照している参照 | コピー先フォルダ内の同じ相対パスのMenu。なければ、コピー先内で唯一の同名ファイル |
| 空欄 | コピー先フォルダの外を参照している参照 | コピー先フォルダ内で唯一の同名ファイル |

コピー元を指定した場合、コピー先に対応するMenuが見つからない参照は**未解決**として一覧に表示されます。

## 注意事項

- 付け替えはUndo(Ctrl+Z)で元に戻せます。
- 処理対象はSubMenu参照のみです。ExpressionParametersやアイコンのテクスチャは変更しません。
- 初めて使うときは、コピー先フォルダのバックアップを取ってから実行すると安心です。
