# ExpressionMenu Relinker

[English](README.md)

コピーしたフォルダ内のVRChat用ExpressionMenuが参照しているSubMenuを、コピー先フォルダ内の対応するMenuへ一括で付け替えるUnity Editor用ツールです。

## コンセプト

ExpressionMenu Relinkerは、VRChatのアバター間でExpressionMenuを複製・管理する作業を簡略化するために開発されました。

新しいアバター用に、関連する複数のExpressionMenuを含むフォルダをコピーした場合、コピー先のMenuは元のフォルダ内にあるSubMenuを参照したままになります。特に階層が深いMenu構造では、参照を1つずつ手動で変更するのは手間がかかります。

このツールでは、コピー先フォルダ内のExpressionMenuをスキャンし、対応するSubMenuを自動的に検索します。変更を適用する前に、付け替え対象を一覧で確認することもできます。

## 概要

- **Unityバージョン：** 2022.3.22f1
- **メニュー：** `nur_ieren > ExpressionMenu 参照付け替え`
- **対応アセット：** VRChat `VRCExpressionsMenu`

## 機能

- **フォルダ指定による参照付け替え** — 指定したコピー先フォルダ内のExpressionMenuを対象に、SubMenuの参照を付け替えます。
- **コピー元フォルダの任意指定** — 元のフォルダを指定することで、コピー先へ付け替えるべき参照を特定できます。
- **パスによる自動照合** — コピー元とコピー先の相対パスを基準に、対応するMenuを検索します。
- **ファイル名による代替照合** — 同じ相対パスのMenuが見つからない場合、コピー先フォルダ内に同名ファイルが1つだけ存在すれば、それを対応先として使用します。
- **参照の自動検出** — コピー先フォルダ内で見つかったすべてのExpressionMenuについて、SubMenu参照をスキャンします。
- **コピー元フォルダなしでの照合** — コピー元を指定しない場合、コピー先フォルダ外を参照しているSubMenuを検出し、ファイル名による照合を試みます。
- **プレビュー・個別選択** — 検出した参照と現在のパス、変更後のパスを一覧表示し、個別に処理対象から除外できます。
- **未解決参照の一覧表示** — コピー元を指定した場合、コピー先に対応するMenuが見つからない参照を一覧表示します。
- **自動再スキャン** — 付け替え実行後にコピー先フォルダを自動的に再スキャンし、残りの対象を確認できます。
- **Undoへの対応** — 変更をUnityのUndoシステムに記録します。

## 動作要件

- Unity 2022.3.22f1
- VRChat SDK3 Avatars（`VRCExpressionsMenu`）

VRC SDKの型を直接参照していません。UnityのAssetDatabaseおよびSerializedObject APIを通じてExpressionMenuのデータにアクセスするため、SDKへのコンパイル時の直接依存を避けています。

## 導入

次の場所にスクリプトを配置してください。

```text
Assets/nur_ieren/ExpressionMenuRelinker/ExpressionMenuRelinker.cs
```

`Editor` フォルダやasmdefは不要です。スクリプト全体を `#if UNITY_EDITOR` で囲んであります。

## 使い方

1. 上部メニューの `nur_ieren > ExpressionMenu 参照付け替え` を開きます。
2. コピーしたExpressionMenuが含まれる**コピー先フォルダ**を指定します。
3. 必要に応じて、元のExpressionMenuが含まれる**コピー元フォルダ**を指定します（任意）。
4. `スキャン` をクリックして、付け替え可能な参照を検索します。
5. 検出された参照と、現在のパス・変更後のパスを確認します。
6. 変更したくない項目があれば、個別にチェックを外します。
7. `付け替え実行` をクリックして変更を適用します。

実行後は自動的にコピー先フォルダが再スキャンされます。残りの対象が0件になれば完了です。

## 付け替えの仕組み

コピー先フォルダ内にあるすべての `VRCExpressionsMenu` アセットを検索し、それぞれのSubMenu参照を調べます。

すでにコピー先フォルダ内を参照しているものは変更しません。

照合方法は、コピー元フォルダを指定しているかどうかによって異なります。

| コピー元フォルダ | 対象となる参照 | 照合方法 |
| --- | --- | --- |
| 指定あり | コピー元フォルダ内を参照しているもの | コピー先フォルダ内の同じ相対パスのMenu。見つからない場合は、同名ファイルがコピー先に1つだけ存在するか確認します。 |
| 指定なし | コピー先フォルダ外を参照しているもの | コピー先フォルダ内で唯一の同名ファイルを検索します。 |

コピー元を指定した場合、コピー元・コピー先のどちらにも属さない参照は処理対象外となります。

また、コピー元を指定していて、コピー先に対応するMenuが見つからない参照は**未解決**として一覧に表示されます。

## 注意事項

- 変更されるのはSubMenu参照のみです。ExpressionParametersやアイコンのテクスチャは変更しません。
- コピー元フォルダの指定は任意ですが、指定することで、より正確に付け替え対象を特定できます。
- コピー元を指定しない場合、同名ファイルがコピー先に複数存在するなど、一意に照合できない参照はスキップされます。この場合、未解決一覧には表示されません。
- プレビュー一覧のチェックを外すことで、個別の参照を処理対象から除外できます。
- 変更はUnityのUndo（`Ctrl + Z`）で元に戻せます。
- 付け替え実行後は自動的に再スキャンされるため、処理結果を確認できます。
- 初めて使用する際は、コピー先フォルダのバックアップを取ってから実行することを推奨します。
